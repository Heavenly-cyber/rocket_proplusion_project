Adds the reproducible container scaffold and verified local software environment for the rocket-nozzle LLM study. Setup commits immutable image/source pins, a hashed transitive dependency lock, build provenance, and actual local verification evidence before this tag is created.

Software checks cover nonroot isolation and resource limits, imports/numerical libraries, success/error cleanup, the fixed GGUF checksum, the direct-answer local API, and removal of owned containers/networks/builders. The manifesto can be exported into a disposable-container result folder.

See `docs/STAGE_03_MANUAL.md` and `docs/STAGE_03_VERIFICATION.json`. Linux amd64 is the initial verified platform. This release contains source and stable receipts only; the 2.55 GiB model, runtime results, logs, and caches remain local. The corpus/benchmark and propulsion accuracy study are later stages. No solved research-gap method or measured domain scores are claimed.
